# 跨境合规结论互认凭证

让境内外机构以可验证的最小凭证互认汇款前合规结论。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括境内金融机构、境外金融机构、进出口企业、合规审计人员。

资料所依据的领域事实如下：

- 跨境资金汇入前由境内外机构同步完成反洗钱筛查
- 审核还包括跨境合规与贸易背景核验
- 核验通过后可实现链上钱包点对点实时到账

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
